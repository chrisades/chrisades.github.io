What am I looking at?

Neural Spectral Automata is a web-tool used to create 1-dimensional neural cellular automata that are mapped to sound. An image is generated row by row using a simple set of rules, and the pixels in that image describe an evolving frequency spectrum over time. Although the rules are simple, surprisingly complex and chaotic patterns emerge from them.

Simple Rules

It starts with a top row of cells, each valued from 0 to 1 (white to black). To grow the row underneath it, every cell goes through the same three steps: a mask convolution, an activation function, and a constraint. The mask is a row of three weights that slide over the cell being processed (center) and its two closest neighbors (left and right), which are multiplied by their matching weights and added together: (left weight × left cell) + (center weight × center cell) + (right weight × right cell). That sum is passed through the chosen activation function, and the result is constrained back to 0 to 1, becoming the new cell. This repeats for every cell, then every row, and the image grows downward on its own.

What "spectral" means here

A row of cells can describe a sound spectrum, where a cell's position stands for a frequency and its value stands for how loud that frequency is. The frequencies can range from tens of Hz at the beginning of the row to about 22,000Hz at the end. Read that way, each row becomes a short snippet of sound, and stitching those snippets together row by row turns the whole pattern into an audible clip.

What "neural" means here

Every cell receives information from itself and its two neighbors, combines that information using a set of weights, and passes the result through an activation function before producing its new value. This is similar in structure to a tiny neural network, but the important difference is that the weights in this web-tool are not learned but are chosen by you, allowing for an explorative experience of a chaotic system.

Grid

Because every row is also a slice of sound, the grid's dimensions shape the audio as much as the image. width controls how many cells are in each row, and also how big each row's sound snippet is: wider rows make longer, more detailed grains of sound, while narrow rows stay short and chirpy. height controls how many rows get generated, and also how many of those grains get stitched together, so a taller grid makes a longer clip.

Initialize

Initialize sets what the first row looks like before the rule starts running.

  • random uniform [0,1]: every cell starts at its own random value.
  • random select (n cells): only n scattered cells start with a random value, the rest start at 0.
  • seed: feeds the random generator, so the same seed always reproduces the same starting row. new picks a fresh one.
  • impulse: there is a single lit cell at a specified position and everything else starts at 0.

Randomize

The randomize button generates a fresh set of parameters for the modules below it all at once.

Mask weights

Set the weight values for the convolutional mask used in the first step of the rule set. Positive and negative values push the pattern in different directions, and small changes here can completely change its behavior. min and max only set the range the sliders are allowed to move in, not the weights themselves.

Activation

Once the mask produces its weighted sum, that value gets inserted into the chosen function (linear, sin, tanh, and others) before becoming the new cell. Some functions fold large values back down, some cut off sharply, and swapping between them is often the single biggest change you can make to the pattern. Whichever one is selected reveals its own sliders underneath, like slope, freq, phase, or mult, to tune its shape.

Boundary & Constraint

wrap controls how the edges of the rows are treated:

  • checked: the leftmost cell's left neighbor is the rightmost cell, and vice versa.
  • unchecked: anything past the edges count as a 0.
mode controls how the activation function's output gets constrained to the range [0, 1]:
  • modulo: keeps only a value's fractional part
  • clip: cuts off a value at 0 if it's less than 0, or 1 if it's greater than 1

Generate audio

Once a pattern is rendered, the generate audio button turns it into sound using an inverse FFT. The clip's natural length comes from the grid width and height. The time × multiplier then stretches or compresses that clip afterward: 1 keeps its natural length, 2 doubles it, 0.5 halves it, all without touching the underlying pattern. The sound clip can then be played and downloaded using the audio player.

Tips and credits

Most parameter configurations are noisy and spectrally rich so be aware of that especially when wearing headphones. Other times an image can be blank except the first row. Despite this, there are surprising sweet spots you can find. A way to find an intriguing pattern is to just explore different configurations by changing the parameters. The randomize button can be useful for this but don’t rely on it to land on a pattern worth saving. You can also fine-tune parameters with the arrow keys on your keyboard.
