Draw2Sound

Draw2Sound is a straightforward wavetable player made in 2024 as a sound source for the Modmatic. Built in Python using the PyQt and Pyo libraries, it allows sounds to be created either by drawing directly in the time canvas or by placing dots in the frequency canvas. The synthesized sound can be heard using the built-in keyboard piano or by connecting a MIDI controller and the audio can be viewed in real-time using the built-in scope or spectrum functions.
